# Laboratory Activity: Recursion

## Brief Description

This laboratory activity focuses on recursion and binary search. The program demonstrates how recursion works and includes a modified binary search program with a search trace.

## Programming Language

Java

## How to Compile and Run

1. Open a terminal or command prompt.
2. Navigate to the folder containing the Java source file.
3. Compile the program using:

```bash
javac Recursion.java
